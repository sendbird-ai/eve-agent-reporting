name: development
description: Inspect a configured repository, implement scoped work and prepare a draft pull request with check and review evidence.
---
Read the repository instructions and requested acceptance criteria. Use research mode for inspection without edits. In development mode, file or reuse the run's audit ticket, apply scoped changes, run the configured checks, review the current diff and publish only a draft pull request. Return missing configuration, failing checks or unavailable review as blockers. Never merge, deploy, expose credentials or widen the configured policy.
